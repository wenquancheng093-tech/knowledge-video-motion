# 画幅与主体适配

动效跨项目复用时保留的是信息关系、遮挡顺序、揭示时机和状态联动；位置、字号、方向和停留时间随内容重算。

| 条件 | 设计要点 |
| --- | --- |
| 16:9 横屏 | 利用左右分区呈现主体与解释；商品数量多时统一卡片字段和基线。 |
| 9:16 竖屏 | 优先上下分区、短行与分页；不要整体缩小横屏画面。当前仓库尚无竖屏示范。 |
| 有人物 | 人脸、手势与关键对象是保护区；文字与卡片避开它们。 |
| 无人物、有商品 | 商品承担视觉主体，人物位置可给商品整体图、局部特写或参数区。 |
| 纯信息 | 标题、论据与结论必须自行讲清楚；用稳定布局承接动态强调。 |
| 有旁白 | 在语义重音处触发动画，保证字幕与卡片不会互相抢读。 |
| 无旁白 | 增加必要解释和阅读停留，不能只保留零碎关键词。 |

替换最长商品名、最大数字和最宽素材后，重新检查裁切、遮挡与移动端字号。演示片的秒数不能直接用于正式讲解。
