# FX-010 并列卡片逐项强调

## 动效效果

本片演示 C 变体：三张商品卡先叠放，再由左向右依次展开。

## 使用场景

三个理由、三个产品或三项差异的并列讲解；C 变体尤其适合三件商品并排呈现。

## 注意点

保持卡片尺寸和字段一致；超过三项时分页。原卡的逐条点亮和人物关键词卡尚未做独立示范。

## 实现要点

- 保留的核心关系：并列信息常驻，当前项目逐条点亮。
- 根据当前文案重新确定字号、元素数量、停留时间及动画触发点；预览的时长仅用于选样。
- 横屏可编辑案例已制作。竖屏和人物／商品／纯信息的其他组合需要按新项目重排并重新渲染。
- 变体范围：只示范 C 变体“三张卡从叠放到横向展开”；原版逐张点亮和人物关键词卡尚无独立示范。
