# 可编辑案例

每个 FX 目录是独立的 HyperFrames HTML 工程；MP4 预览已提供，编辑动画前在本目录运行 `npm install` 准备 GSAP。工程默认使用系统中文字体；预览由制作环境渲染，换字体或文案后需重新检查排版。
