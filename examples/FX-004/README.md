# FX-004 提问与答案叠层｜可编辑横屏示范

- [观看 5 秒以内的 MP4](../../demos/FX-004-preview.mp4) · [关键画面](preview-contact.jpg)
- [修改文字与商品数据](data/content.js) · [修改动画](index.html) · [查看配方](../../references/recipes/FX-004.md)

这是 16:9 的通用机制案例，画面内容是占位示范。正式视频按真实文案、素材和阅读时间重排。当前工程使用 GSAP；先在上层 `examples/` 目录运行 `npm install` 来准备本地脚本。字体默认使用系统中文无衬线字体。

本例覆盖范围：A 变体：提问与背景问号。其他标题叠层方式尚无独立示范。
