- [修改文字与商品数据](data/content.js) · [修改动画](index.html) · [查看配方](../../references/recipes/FX-010.md)

这是 16:9 的通用机制案例，画面内容是占位示范。正式视频按真实文案、素材和阅读时间重排。当前工程使用 GSAP；先在上层 `examples/` 目录运行 `npm install` 来准备本地脚本。字体默认使用系统中文无衬线字体。

本例覆盖范围：只示范 C 变体“三张卡从叠放到横向展开”；原版逐张点亮和人物关键词卡尚无独立示范。
